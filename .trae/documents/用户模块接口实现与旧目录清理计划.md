## 2. 实现用户模块四个接口

### 2.1 数据库设计
- 创建用户表 `sys_user`，包含以下字段：
  - id: BIGINT (主键)
  - username: VARCHAR(50) (用户名，唯一)
  - password: VARCHAR(255) (密码，加密存储)
  - nickname: VARCHAR(50) (昵称)
  - studentId: VARCHAR(20) (学号，唯一)
  - phone: VARCHAR(20) (手机号)
  - campus: VARCHAR(50) (校区)
  - avatarUrl: VARCHAR(500) (头像URL)
  - creditScore: INT (信用分，默认95)
  - token: VARCHAR(500) (JWT令牌)
  - createTime: DATETIME (创建时间)
  - updateTime: DATETIME (更新时间)

### 2.2 代码实现

#### 2.2.1 Domain层
- 创建 `User.java` 实体类，对应 `sys_user` 表

#### 2.2.2 Mapper层
- 创建 `UserMapper.java` 接口，实现基本的CRUD操作
- 包含方法：`insert`, `selectByUsername`, `selectById`, `updateById`

#### 2.2.3 Service层
- 创建 `UserService.java` 接口
- 实现 `UserServiceImpl.java` 类
- 实现方法：
  - `register`: 用户注册，包含密码加密
  - `login`: 用户登录，生成JWT令牌
  - `getUserInfo`: 获取当前用户信息
  - `updateUserInfo`: 更新用户信息

#### 2.2.4 Controller层
- 创建 `UserController.java` 类
- 实现四个接口：
  - `POST /api/user/register`: 用户注册
  - `POST /api/user/login`: 用户登录
  - `GET /api/user/me`: 获取当前用户信息
  - `PUT /api/user/update`: 修改用户信息

### 2.3 JWT配置
- 添加JWT依赖（jjwt）
- 创建JWT工具类，实现令牌生成和验证
- 添加拦截器，验证需要登录的接口

### 2.4 安全配置
- 添加密码加密依赖（Spring Security Crypto）
- 实现密码加密和验证
